# SeunghwanByun.github.io

Personal research blog for GitHub Pages.

## Structure

- `index.html`: blog home and recent posts
- `about.html`: profile and current interests
- `research.html`: categorized paper notes and development posts
- `curriculum.html`: empty study roadmap and topic list
- `posts/`: individual blog posts
- `projects.html`: project notes
- `roadmap.html`: research and study plan
- `styles.css`: simple blog layout
- `assets/research-workspace.png`: small profile image

## Writing Posts

1. Add a new HTML file under `posts/`.
2. Link the post from `research.html`.
3. Add it to `index.html` if it should appear in Recent Posts.

Open `index.html` in a browser or publish the repository with GitHub Pages.
